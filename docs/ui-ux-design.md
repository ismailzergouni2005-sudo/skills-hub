# 11. UI/UX Design

> Designing digital experiences that people actually enjoy using — research, flows, wireframes, prototypes.

## 🧭 Roadmap

1. UX fundamentals → 2. User research → 3. Information architecture & flows → 4. Wireframes (Figma) → 5. Visual design → 6. Interactive prototypes → 7. Usability testing → 8. Design systems & handoff

| Skill | Why it matters | Learn it (free) | Advanced |
