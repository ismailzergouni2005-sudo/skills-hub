# 1. Programming Fundamentals

> The starting point of every technical career: how computers, code, and logic actually work.

## 🧭 Roadmap

1. How computers work → 2. Pick one beginner language (Python is recommended) → 3. Variables, conditions, loops → 4. Functions & data structures → 5. Problem solving & algorithms → 6. Object-oriented programming → 7. Version control (Git) → 8. Small projects

## 🛠️ Core Skills

| Skill | Why it matters | Learn it (free) | Advanced |
|-------|----------------|-----------------|----------|
| How computers work | Understand memory, CPU, and how code runs | [CS50 (Harvard) — Free](https://cs50.harvard.edu/x/) | — |
| Python | The best first language; used in AI, data, automation | [Python Official Tutorial](https://docs.python.org/3/tutorial/) • [freeCodeCamp Python](https://www.freecodecamp.org/learn/) | [Python Docs — Advanced](https://docs.python.org/3/) |
| JavaScript | The language of the web | [JavaScript.info](https://javascript.info/) | [MDN Advanced](https://developer.mozilla.org/en-US/docs/Web/JavaScript) |
| Data structures & algorithms | The core of technical interviews | [VisuAlgo (visual explanation)](https://visualgo.net/en) | [NeetCode Roadmap](https://neetcode.io/roadmap) |
| Problem solving (competitive) | Turns knowledge into real ability | [Codeforces](https://codeforces.com/) • [LeetCode](https://leetcode.com/) | [Codeforces Div1 problems](https://codeforces.com/problemset) |
| Object-Oriented Programming (OOP) | How real software is organized | [Python OOP — Real Python](https://realpython.com/python3-object-oriented-programming/) | — |
| Git & GitHub | Track code, collaborate with the world | [Git Official Book](https://git-scm.com/book/en/v2) • [Exercism Git track](https://exercism.org/tracks) | [Advanced Git](https://git-scm.com/doc) |
| Computer Networks basics | Everything talks over a network | [Practical Networking (free series)](https://www.practicalnetworking.net/series/packet-traveling/packet-traveling/) | [Beej's Guide to Networking](https://beej.us/guide/bgnet/) |
| Command line (CLI) | Automate everything faster | [MIT Missing Semester](https://missing.csail.mit.edu/) | — |
| Databases (SQL) | Store and retrieve data correctly | [SQLBolt (interactive)](https://sqlbolt.com/) | [SQL Window Functions](https://mode.com/sql-tutorial/sql-window-functions/) |
