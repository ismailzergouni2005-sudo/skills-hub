# 3. Backend Development

> Server-side engineering: APIs, business logic, databases, and the systems behind every app.

## 🧭 Roadmap

1. A language (Python / Node / Java / C#) → 2. HTTP & APIs → 3. Relational databases & SQL → 4. Authentication & security basics → 5. Building a full REST API → 6. Caching, testing, deployment → 7. Scaling & architecture
