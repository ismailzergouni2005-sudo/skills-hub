# 8. Cloud & DevOps

> Running applications reliably at scale: cloud platforms, containers, automation, and CI/CD.

## 🧭 Roadmap

1. Linux + networking → 2. One cloud (AWS or Azure) → 3. Docker → 4. CI/CD pipelines → 5. Kubernetes → 6. Infrastructure as Code (Terraform) → 7. Monitoring & SRE thinking
