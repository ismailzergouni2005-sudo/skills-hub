# 4. Mobile Development

> Building apps for Android and iOS — from native platforms to cross-platform frameworks.

## 🧭 Roadmap

1. Pick a path: native (Kotlin/Swift) or cross-platform (Flutter/React Native) → 2. Language basics → 3. UI layout → 4. State management → 5. Networking & storage → 6. Build & publish a real app → 7. Advanced: push notifications, native APIs

## 🛠️ Core Skills

| Skill | Why it matters | Learn it (free) | Advanced |
|-------|----------------|-----------------|----------|
| Flutter / Dart | One codebase → Android + iOS + Web | [Flutter Official Codelabs](https://docs.flutter.dev/get-started/codelab) | [Flutter Advanced (state, native)](https://docs.flutter.dev/) |
| Kotlin + Android | Native Android (Google's official) | [Android Basics with Compose (free, official)](https://developer.android.com/courses/android-basics-compose/course) | [Advanced Android](https://developer.android.com/courses) |
| Swift + SwiftUI | Native iOS (Apple's official) | [Swift Book (Apple)](https://docs.swift.org/swift-book/) • [100 Days of SwiftUI (free)](https://www.hackingwithswift.com/100/swiftui) | — |
| React Native | Use your React knowledge for mobile | [React Native Official](https://reactnative.dev/docs/getting-started) | — |
| Mobile UI/UX | Touch-first, small screens | [Material Design 3](https://m3.material.io/) • [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/) | — |
| Local storage (SQLite / Hive / Core Data) | Apps must work offline | [Flutter Cookbook — Persistence](https://docs.flutter.dev/cookbook/persistence) | — |
| Networking (REST from mobile) | Every app talks to a backend | [Android networking](https://developer.android.com/guide/topics/network) | — |
| Push notifications | Core mechanism of engagement | [Firebase Docs — Free](https://firebase.google.com/docs) | — |
| App Store / Play Store publishing | Take the app to real users | [Publishing (Flutter)](https://docs.flutter.dev/deployment/android) | — |
