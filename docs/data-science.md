# 6. Data Science & Analytics

> Turning raw data into decisions: statistics, SQL, dashboards, and storytelling with numbers.

## 🧭 Roadmap

1. Spreadsheet mastery → 2. SQL → 3. Python/R for analysis → 4. Statistics → 5. Visualization & BI dashboards (Power BI/Tableau) → 6. Real projects & reports → 7. Data engineering basics (optional)

## 🛠️ Core Skills

| Skill | Why it matters | Learn it (free) | Advanced |
|-------|----------------|-----------------|----------|
| Excel / Google Sheets | The everyday tool of every business | [Microsoft Excel training — Free](https://support.microsoft.com/en-us/excel) | — |
| SQL | #1 skill in all data jobs | [SQLBolt](https://sqlbolt.com/) • [Mode SQL Tutorial](https://mode.com/sql-tutorial/) | [Advanced SQL — Mode](https://mode.com/sql-tutorial/sql-window-functions/) |
| Python (pandas) | Automate any analysis | [Kaggle Learn — pandas](https://www.kaggle.com/learn/pandas) | [pandas User Guide](https://pandas.pydata.org/docs/user_guide/index.html) |
| R (optional but respected) | Statistics-native language | [R for Data Science (free book)](https://r4ds.hadley.nz/) | — |
| Statistics | Separate signal from noise | [StatQuest (YouTube, free)](https://www.youtube.com/@statquest) • [OpenIntro Stats (free book)](https://www.openintro.org/book/os/) | — |
| Data visualization | One good chart beats 1000 tables | [Data Visualization — Kaggle](https://www.kaggle.com/learn/data-visualization) • [From Data to Viz](https://www.data-to-viz.com/) | — |
| Power BI | Most requested BI tool in jobs | [Microsoft Learn — Power BI (free)](https://learn.microsoft.com/en-us/training/browse/?products=power-bi) | — |
| Tableau | The other BI giant | [Tableau Public + free training](https://www.tableau.com/learn/training) | — |
| ETL / dbt basics | Clean data pipelines | [dbt Fundamentals (free)](https://courses.getdbt.com/courses/fundamentals) | — |
| Storytelling with data | Turn analysis into decisions | [Storytelling with Data — free resources](https://www.storytellingwithdata.com/blog) | — |
