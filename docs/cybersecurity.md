# 7. Cybersecurity

> Protecting systems and breaking into them (legally!) — offense, defense, and everything in between.

## 🧭 Roadmap

1. Networking & Linux basics → 2. Security fundamentals (CIA, cryptography) → 3. Pick a track (Red/Blue/Purple) → 4. Hands-on labs → 5. Certifications (CompTIA Security+/OSCP) → 6. Real-world practice (CTFs, bug bounty)
