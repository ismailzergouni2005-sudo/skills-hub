# 18. Languages

> The multipliers of every career. English is the world default; each extra language multiplies your market.

## 🧭 Roadmap

1. Choose a target language + level goal (e.g., B2 in English) → 2. Vocabulary + listening daily → 3. Grammar in context → 4. Speaking practice (even alone!) → 5. Certified test (IELTS/Duolingo test) → 6. Maintain with media you consume

## 🤝 Professional Skills

| Skill | Notes | Resource |
|-------|-------|----------|
| Business vocabulary for your field | "Deploy", "escalate", "invoice" ... | Field-specific podcasts & docs read in the target language |
| Interviewing in your target language | Common but feared — practice out loud | Mock interviews with language partners |
| Cross-cultural communication | Direct vs indirect cultures | [Erin Meyer — The Culture Map (resources)](https://erinmeyer.com/books/the-culture-map/) |
| Consistent daily input (30 min/day) | Languages are built by repetition | Input before output; streaks matter |
