# 5. AI & Machine Learning

> Building systems that learn from data — from classical ML to generative AI and LLM applications.

## 🧭 Roadmap

1. Python + linear algebra + probability → 2. Classical ML (scikit-learn) → 3. Deep learning (PyTorch) → 4. Computer vision or NLP → 5. Transformers & LLMs → 6. Build real applications (RAG, agents, fine-tuning)

| Skill | Why it matters | Learn it (free) | Advanced |
|-------|----------------|-----------------|----------|
| Math for ML | The language of all models | [Khan Academy — Linear Algebra](https://www.khanacademy.org/math/linear-algebra) • [3Blue1Brown](https://www.3blue1brown.com/topics/neural-networks) | [Mathematics for ML (free book)](https://mml-book.github.io/) |
| Classical ML (scikit-learn) | Regression, trees, clustering — still 80% of real work | [Google ML Crash Course (free)](https://developers.google.com/machine-learning/crash-course) | [scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html) |
| Deep Learning (PyTorch) | The industry-standard framework | [Official 60-min Blitz](https://pytorch.org/tutorials/beginner/deep_learning_60min_blitz.html) | [Deep Learning Specialization (audit free)](https://www.coursera.org/specializations/deep-learning) |
| fast.ai (top-down learning) | Fastest free path to real DL | [Practical Deep Learning (fast.ai, free)](https://course.fast.ai/) | — |
