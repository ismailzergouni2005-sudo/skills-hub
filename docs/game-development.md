# 9. Game Development

> Designing and building video games — programming, art, sound, and pure fun engineering.

## 🧭 Roadmap

1. Pick an engine (Unity or Godot for beginners) → 2. Engine basics → 3. C#/GDScript fundamentals → 4. Physics & collisions → 5. Build 3 tiny games → 6. Game design (fun, balance) → 7. Level design → 8. Polish & publishing
