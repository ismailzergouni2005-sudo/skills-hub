# 2. Web Development (Frontend)

> Building what users see and interact with: websites, web apps, and interfaces.

## 🧭 Roadmap

1. HTML → 2. CSS → 3. JavaScript → 4. Responsive design → 5. Git → 6. React (or Vue/other framework) → 7. Build real projects → 8. Performance & accessibility

## 🛠️ Core Skills

| Skill | Why it matters | Learn it (free) | Advanced |
|-------|----------------|-----------------|----------|
| HTML | The skeleton of every page | [MDN HTML](https://developer.mozilla.org/en-US/docs/Learn/HTML) | [MDN Web APIs](https://developer.mozilla.org/en-US/docs/Web/API) |
| CSS | Colors, layout, animation | [CSS in 100 pages — web.dev](https://web.dev/learn/css) | [CSS-Tricks Guides](https://css-tricks.com/guides/) |
| Flexbox & Grid | Modern page layout | [Flexbox Froggy (game)](https://flexboxfroggy.com/) • [Grid Garden](https://cssgridgarden.com/) | [Grid Guide — CSS-Tricks](https://css-tricks.com/snippets/css/complete-guide-grid/) |
| JavaScript | Interactivity & logic | [JavaScript.info](https://javascript.info/) | [MDN JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) |
| Responsive design | Same site works on phone & desktop | [web.dev Responsive](https://web.dev/learn/design/) | — |
| React | Most in-demand frontend framework | [React Official Tutorial](https://react.dev/learn) | [React Docs — Advanced patterns](https://react.dev/reference/react) |
| TypeScript | Safer JavaScript for big projects | [TS Handbook](https://www.typescriptlang.org/docs/handbook/) | [Type Challenges](https://github.com/type-challenges/type-challenges) |
| Accessibility (a11y) | Usable by everyone — required professionally | [web.dev Accessibility](https://web.dev/learn/accessibility/) | — |
| Performance | Fast sites rank better and sell better | [web.dev Performance](https://web.dev/performance) | [Lighthouse](https://developer.chrome.com/docs/lighthouse/) |
| Framer Motion / CSS animation | Modern interfaces move | [Framer Motion docs](https://motion.dev/) | — |
