## 🤝 Workplace habits that set you apart

| Habit | Why | How to start |
|-------|-----|--------------|
| Follow-through (do what you said) | Trust is built this way | Deliver small promises at work daily |
| Proactive communication | Managers love "no surprises" | Send short weekly updates without being asked |
| Asking good questions | Signals preparation | Question journals before 1:1s |
| Documenting your work | Makes you promotable and hireable | Keep a "wins" document |
| Continuous learning | Skills expire; learning doesn't | Read 20 min/day in your field |
