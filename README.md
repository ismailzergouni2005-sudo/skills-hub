# 🌟 Skills Hub — Every Skill, One Place

> **A complete directory of skills for every field.** Pick your field, get a structured list of the skills you need, and direct links to the best free resources to learn each one — plus the professional (soft) skills that make people in that field successful.

## 📖 How to use this project

1. **Choose your field** from the index below.
2. Click the field name — it opens a full page for that field.
3. Every page gives you:
   - 🧭 A **learning roadmap** (what to learn, in what order)
   - 🛠️ **Technical / learning skills** — each with descriptions and direct resource links
   - 🤝 **Professional (soft) skills** for that field
   - 📚 A list of **free and paid platforms** to master the field

## 🧭 How each skill page is organized

Every field page follows the same template:

```markdown
# Field Name
A one-line description of the field.

## 🧭 Roadmap           → the recommended learning order

## 🛠️ Core Skills
| Skill | Why it matters | Learn it (free) | Advanced |
|-------|----------------|-----------------|----------|

## 🤝 Professional Skills
Table with soft skills specific to this field.

## 📚 Learning platforms
Free and paid platforms ranked by usefulness for this field.
```

## 🤝 Contributing

Contributions are welcome! Read [CONTRIBUTING.md](CONTRIBUTING.md) to add:

- A **new field** (create `docs/<field-name>.md` using the template above)
- A **new skill or resource** to an existing field
- Any **dead-link fix** (open an issue or PR)

All links should preferably point to **high-quality free resources** (paid ones are allowed but must be noted as paid).
