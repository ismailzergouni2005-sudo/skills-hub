# 🌟 Skills Hub — فهرس مهارات وكلاء الذكاء الاصطناعي على GitHub

> **Agent Skills Directory** — كل مهارات الوكلاء (AI Agents) الموجودة على GitHub في مكان واحد، مصنّفة حسب المجال.
> اختر مجالك وشاهد كل المهارات المتوفرة فيه مع وصفها ورابطها المباشر.

🎯 **الموقع التفاعلي:** افتح [`index.html`](index.html) — بحث فوري + تصفّح حسب المجال + روابط مباشرة لكل مهارة.

المهارات هنا تعتمد **معيار Agent Skills المفتوح** ([agentskills.io](https://agentskills.io)) — ملف `SKILL.md` واحد يعلّم أي وكيل (Claude Code · OpenAI Codex · Cursor · Gemini CLI · GitHub Copilot · OpenCode) كيفية تنفيذ مهمة معينة باحتراف.

## 🧩 كيف أثبّت أي مهارة؟

**في Claude Code:**
```bash
# المجلس الفردي — انسخ مجلد المهارة في موضع مهاراتك الشخصية
git clone https://github.com/anthropics/skills ~/.claude/skills/anthropic-skills

# أو عبر نظام البرنامج الإضافي (Plugin Marketplace):
/plugin marketplace add anthropics/skills
```

**في Claude.ai / Claude Cowork:** الإعدادات ← `Customize` ← `Skills` ← **＋** ← ارفع ملف `SKILL.md` أو ملف `zip` الخاص بالمهارة.

**في Codex / Cursor / Gemini CLI / OpenCode:** انسخ مجلد المهارة إلى مسار `skills` الخاص بالأداة — المعيار واحد للجميع ([agentskills.io](https://agentskills.io)).

> ⚠️ **ملاحظة أمان:** المهارات ملفات نصية آمنة، لكن راجع أي سكربت داخلها قبل تشغيله، وفضّل المستودعات ذات النجوم العالية والسجلات النشطة.
